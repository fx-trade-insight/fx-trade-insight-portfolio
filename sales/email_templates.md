# メールテンプレート集

---

## 自動送信メール（GAS）

### 1. ライセンスキー送信メール

購入者がフォームから申請した際に GAS が自動送信します。

**件名**
```
【FX Trade Insight】ライセンスキーのご案内
```

**本文**
```
FX Trade Insight をご購入いただきありがとうございます。

ライセンスキー: FTI-XXXX-XXXX-XXXX

アプリを起動するとライセンスキー入力画面が表示されます。
このメールに記載のキーをそのまま入力して「認証する」ボタンを押してください。

─────────────────────────────
■ ご利用上の注意
・1つのライセンスキーはPC買い替え・移行に対応するため、最大2台のPCで同時にご利用いただけます。
・PC交換後に不要になった旧PCの登録を削除する場合はお問い合わせください。
─────────────────────────────
ご不明な点はお気軽にお問い合わせください。
makio.app@gmail.com
```

---

### 2. ライセンスキー申請エラーメール

申請時に問題があった場合に GAS が自動送信します。

**件名**
```
【FX Trade Insight】ライセンスキー申請の確認をお願いします
```

**本文**
```
FX Trade Insight のライセンスキー申請に問題がありました。

（エラー詳細メッセージ）

note の購入完了メールに記載されている注文IDをご確認の上、
再度フォームからお申し込みください。

ご不明な点はお問い合わせください。
makio.app@gmail.com
```

## 手動送信メール

### 3. お問い合わせ返信（一般）

Discord に届いた問い合わせへの返信テンプレート。

**件名**
```
Re: 【FX Trade Insight】お問い合わせについて
```

**本文**
```
お問い合わせいただきありがとうございます。

（回答内容）

引き続きご不明な点がございましたら、お気軽にご連絡ください。

FX Trade Insight サポート
makio.app@gmail.com
```

---

### 4. お問い合わせ返信（ライセンス台数上限解除）

MACHINE_LIMIT_EXCEEDED でお問い合わせがあった場合。

**件名**
```
Re: 【FX Trade Insight】登録台数上限について
```

**本文**
```
お問い合わせいただきありがとうございます。

ご登録PCの情報をリセットいたしました。
お手数ですが、アプリを再起動してライセンスキーを再入力してください。

※ 再起動後、自動的に認証が完了します。

ご不明な点がございましたら、お気軽にご連絡ください。

FX Trade Insight サポート
makio.app@gmail.com
```

---

## 備考

- 問い合わせはアプリ内フォーム → GAS 経由で **Discord に届く**（メール通知ではない）
- ライセンスキー再送が必要な場合（紛失等）：同じ注文番号で再申請すると同じキーが自動再送される
- 台数上限解除対応：GASのスプレッドシート「ライセンス管理」シートで対象行のマシンIDをすべて削除 → ユーザーに再起動を案内
